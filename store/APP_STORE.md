# App Store listing: Vompt 1.0

Everything to enter in App Store Connect, field by field. Character counts are checked against Apple's limits.

## Before you submit

1. **Signing.** Put your Apple Developer Team ID in `vompt/ios/Flutter/Signing.xcconfig` (copy the `.example` next to it). The file is git-ignored.
2. **Bundle ID.** The App Store Connect record uses `com.fluttele.fluttele`, a leftover from the app's working name. Users never see it, and changing it would mean a new App Store record, so keep it.
3. **Build numbers.** Every upload needs a higher build number than the last. They are date-based: `version: 1.0.0+2026110701` in `vompt/pubspec.yaml` means 1.0.0 (2026110701); the next upload that day is `...02`, the next day `2026110801`.
4. **Upload a build:**
   ```bash
   cd vompt
   flutter build ipa --release
   ```
   Then either drag `build/ios/ipa/*.ipa` into Transporter, or upload straight from the archive with
   `xcodebuild -exportArchive -archivePath build/ios/archive/Runner.xcarchive -exportOptionsPlist <plist> -allowProvisioningUpdates`,
   where the plist sets `method` to `app-store-connect`, `destination` to `upload` and your `teamID`.
   The build appears in App Store Connect under TestFlight after processing (usually 10 to 30 minutes).

   If the export stops with "Copy failed", a Homebrew `rsync` is shadowing the system one. Run the
   `xcodebuild` command with `env PATH=/usr/bin:/bin:/usr/sbin:/sbin` in front of it.

## App Review information

- Sign-in required: **No**
- Contact: your name, phone and email (Apple uses these only if the reviewer has a question)
- Notes for the reviewer:

```
Vompt is a teleprompter that follows the reader's voice. No account or sign-in.

To try it:
1. Open the script "Welcome to Vompt" on the first screen.
2. Tap Rehearse, then Start, and allow the microphone.
3. Read the text aloud. The highlighted word follows your voice and the text scrolls.
4. Tap the screen, then Finish take, to see pace, filler words and skipped lines.

The microphone is used only while the prompter shows "Listening". Speech is recognized on the device with Apple's Speech framework; nothing is recorded or uploaded.

Assist (sparkle icon in the editor) uses Apple Intelligence through the Foundation Models framework and appears as unavailable on devices without it.

The Remote button turns on an optional local web page (Vompt Studio) so a computer on the same Wi-Fi can edit scripts and control the prompter. It uses the local network only and requires a private link shown on the device. This is why the app asks for local network access.
```

## Export compliance

Answered in the build (`ITSAppUsesNonExemptEncryption = NO` in Info.plist): the app uses no encryption beyond what iOS provides, so App Store Connect won't ask on each upload.
